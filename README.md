# 💈 Barber Booking

A simple booking system built with PHP and MySQL to practice backend development.

Customers can choose a service, select a date and available time, and create or cancel a booking.

Admins can log in to manage bookings.

## Features

- Create bookings
- Choose service, date and time
- Display available booking times
- Prevent double bookings
- Cancel bookings
- Admin login
- Manage bookings as admin

## Built With

- PHP
- MySQL
- PDO
- JavaScript
- HTML & CSS

## What I Practiced

- PHP fundamentals
- Routing and controllers
- MySQL and PDO
- CRUD operations
- Forms and POST requests
- Working with dates and times
- Sessions and authentication
- Admin functionality
- JavaScript together with PHP
